# systems/seo.md — SEO, Structured Data & Sitemaps

## Purpose

Ensure every compiled page is discoverable by search engines with correct metadata,
structured data, canonical URLs, and sitemap entries.

---

## Responsibilities

1. Inject `<title>`, `<meta name="description">`, Open Graph tags into every page
2. Build JSON-LD structured data appropriate to each page type
3. Generate canonical URL `<link>` tags
4. Write `sitemap.xml` covering all compiled pages
5. Write `robots.txt` pointing to the sitemap
6. Never fabricate SEO metadata — only use data present in `source.json`

---

## Where SEO is Applied

SEO injection happens in **`renderer/engine.py`'s `render_resolved()`**:
- Meta tags are inserted into the template context dict
- JSON-LD scripts are passed as a list (`structured_data`) and rendered in the template `<head>`

SEO is **not** applied in templates directly — templates only render the context they receive.

---

## Meta Tags

| Tag | Source field | Fallback |
|---|---|---|
| `<title>` | `seo_title` | `program_name` / `spec_name` / `university_name` |
| `<meta description>` | `meta_description` | `hero_description` (truncated) |
| `og:title` | `seo_title` | Same as `<title>` |
| `og:description` | `meta_description` | Same as `<meta description>` |
| `og:image` | `hero_image_url` | None (omitted if absent) |
| `og:type` | Derived from `page_type` | `website` |
| `canonical` | Computed from `primary_domain` + public route | — |

## JSON-LD Structured Data

`_build_structured_data()` in `engine.py` returns a list of JSON-LD graphs:

### BreadcrumbList (all pages)
```json
{
  "@type": "BreadcrumbList",
  "itemListElement": [
    {"@type": "ListItem", "position": 1, "name": "Home", "item": "https://..."},
    {"@type": "ListItem", "position": 2, "name": "Programs", "item": "https://.../programs"},
    {"@type": "ListItem", "position": 3, "name": "MBA Finance", "item": "https://..."}
  ]
}
```

### Organization (university pages only)
```json
{
  "@type": "Organization",
  "name": "NMIMS Online",
  "url": "https://...",
  "logo": "https://.../assets/images/logo.png"
}
```

### Course (course and specialization pages)
```json
{
  "@type": "Course",
  "name": "MBA Finance",
  "description": "...",
  "provider": { "@type": "Organization", "name": "NMIMS Online" },
  "offers": { "@type": "Offer", "price": "120000", "priceCurrency": "INR" }
}
```
Price is extracted via `_schema_price()` — reads numeric value from raw fee fields
**without inventing a value** if absent.

### FAQPage (course, specialization, blog — if FAQs exist)
```json
{
  "@type": "FAQPage",
  "mainEntity": [
    { "@type": "Question", "name": "...", "acceptedAnswer": {"@type": "Answer", "text": "..."} }
  ]
}
```

## Canonical URLs

Built by `core/utils.build_public_url(primary_domain, route)`.

`primary_domain` is resolved from:
1. `metadata.json["primary_domain"]` in the workspace
2. `LEAD_BASE_URL` environment variable (fallback)

Routes are built by `core/utils.build_public_route(page_type, slug, university_slug)`.

---

## Sitemap

Generated by `builder.py` at build time. Covers:
- University homepage (`/`)
- Programs listing (`/programs`)
- Specializations listing (`/specializations`)
- Blog listing (`/blog`)
- All course pages
- All specialization pages
- All blog posts

Format:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://primary-domain.com/</loc>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
  </url>
  ...
</urlset>
```

---

## robots.txt

```
User-agent: *
Allow: /
Sitemap: https://primary-domain.com/sitemap.xml
```

Generated by `builder.py`. `sitemap` line uses the `primary_domain`.

## Known Limitations

- **Per-page `lastmod` IS emitted** (corrected 2026-07-24 audit): `builder.py::_write_sitemap`
  writes a `<lastmod>` per URL via its `_lastmod(record)` helper (course/spec/blog use each
  record's data; listing/home use `last_compiled_at`). The earlier claim that sitemap had no
  lastmod was outdated.
- **FAQPage JSON-LD can carry fabricated FAQs:** because `renderer/engine.py` substitutes
  hardcoded FAQs when a page has none, the `FAQPage` structured data may contain invented Q&A.
  See `HARDCODED_CONTENT_AUDIT.md` (C3) and `memory/regressions.md` REG-010.
- **`primary_domain` may be absent:** If the workspace has no `primary_domain` in
  `metadata.json` and `LEAD_BASE_URL` is different from the actual site domain, the
  canonical URLs and sitemap URLs will point to the wrong domain.
- **No hreflang:** All content is in English/Hindi for an Indian audience. No multilingual
  SEO tags are implemented.
- **SEO fields are optional in DOCX:** If the operator doesn't provide `seo_title` and
  `meta_description` in the DOCX, the fallback values may be less optimal for search ranking.
